原来的博客部署在云服务器上，需要自己维护 Nginx、公网带宽与系统安全。

<!-- more -->

迁移到 GitHub Pages 之后，文章源码会保存在 GitHub 仓库中。每次提交文章，GitHub Actions 会自动生成并发布网页。

## 保留下来的内容

- 原来的动漫风页面。
- 动态视频背景及静态备用背景。
- 蕾姆 Live2D 看板娘。
- 鼠标星点拖尾和点击特效。

变化的只是发布方式，熟悉的页面仍然在。
